# PeopleOps — Human Resource Management System (HRMS)

PeopleOps is a Spring Boot backend application for managing human resources processes, including employees, departments, recruitment, onboarding, attendance, leave, payroll, performance, training, assets, documents, and offboarding.

## Tech Stack
- Java 17 / Spring Boot 3.x
- PostgreSQL Database
- Spring Data JPA / Hibernate
- Maven
